# Historical ticket archive

The T01–T15 files record an earlier, much broader adoption roadmap. They are
useful design history, but they are not Chutni's current task queue and do not
all need to be completed before Samosa can use Chutni.

The active completion state is [docs/TASKS.md](../TASKS.md). The application
boundary Samosa relies on is
[docs/SAMOSA-COMPATIBILITY.md](../SAMOSA-COMPATIBILITY.md).

Work already retained from this track:

- T01: universal JSON call surface
- T02: Python binding
- T05: Codex/MCP integration
- T06: implementer's quickstart

Standalone application/model memory and the Samosa compatibility gate were
completed after this roadmap was archived.

Unfinished tickets describe optional future work—pack/remap, measurement,
TypeScript, Windows, publication, and similar expansion. Reopen one only when a
real consumer need makes it the next task.

The original index, priorities, and dependency graph are preserved in
[the archived adoption track](../archive/TICKETS-2026-07-30-adoption-track.md).
